After MVP

Voice cloning, Calibre bridge for more formats, OCR, more engines, SML tags, more languages.

Top risks

  • Small local LLM misattributes speakers. Mitigation: hybrid rules for easy cases, review screen.
  • Hardware floor too low for multi-voice. Mitigation: two tiers.
  • Synthesis takes too long. Mitigation: ETA, resume, fast VITS voices for drafts.
  • Model licences block sharing. Mitigation: check in phase 0.
