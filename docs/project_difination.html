Castbook: project definition

Working title. Local, offline book-to-audiobook converter with a separate voice for the narrator and each character.

Problem

Existing tools (e.g. ebook2audiobook) read a whole book in one voice. Castbook adds a casting layer: it finds who speaks each line and gives every character a consistent voice, across all chapters.

Constraints

  • Fully offline. No network calls after models are downloaded.
  • Two hardware tiers. Narrator-only mode targets the reference floor (2 GB RAM, 1 GB VRAM, VITS). Multi-voice mode needs a local LLM, so it has a higher floor (proposed: 8 GB RAM; a 3B-class 4-bit model is roughly 2-3 GB). Benchmark before promising this.
  • Sequential stages. Never hold the LLM and the TTS model in memory together.
  • Licensing. Check each model licence before distributing. As far as I know XTTSv2 is non-commercial only.
  • Books are copyrighted. The tool processes files the user owns; it ships no book content.

Success criteria

  • At least 90% of quoted lines get the right speaker on a 3-chapter test set you hand-label (target; measure it in the spike).
  • A character sounds the same in chapter 1 and chapter 30.
  • A killed run resumes without redoing finished segments.

Glossary

Segment: one span of text with one speaker. Cast: the list of characters and their voices. Alias: another name for the same character.
